# Task: Implement the checkers engine

Implement a checkers game engine in Rust.

Requirements:
- Standard 8x8 board
- Two players: red and black
- Standard American checkers rules
- Legal diagonal movement
- Mandatory captures and multiple jumps
- Promotion to kings
- Turn management
- Game-over detection

Constraints:
- No web server yet
- No external dependencies unless necessary
- Separate game logic from presentation
- Add comprehensive unit tests
- Follow idiomatic Rust conventions

Acceptance criteria:
- cargo test passes
- cargo clippy reports no warnings
- cargo fmt --check passes
